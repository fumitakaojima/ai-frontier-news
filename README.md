# ai-frontier-news
AI最前線新聞（AI FRONTIER）は、AI技術の公式発表、研究論文、開発ツールの更新、専門家・実践者の公開情報を収集・検証し、日本語で届けるニュースサイトです。OpenAI、Anthropic、Google DeepMind、xAI、Cursor、GitHubなどを横断し、技術的ブレークスルーと今すぐ使える実践知をバランスよく紹介します。一般読者向けの30秒要約と、開発者向けの技術解説を一体化し、出典・発表日・訂正履歴を明示。記事の選定・生成・品質検査・公開を自動化し、Astro、Cloudflare Pages、GitHub Actionsの無料枠を活用して月額0円運用を目指します。公開サイトのコードと記事を管理するリポジトリであり、非公開のCodex実験室や認証情報は含みません。
